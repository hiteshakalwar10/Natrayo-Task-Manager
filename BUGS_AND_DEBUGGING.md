# NATRAYO Task Manager — Bugs and Debugging

## 1. Purpose

This document records bugs found during development, the cause of each bug, the fix, and the testing performed after the fix.

## 2. Bug Log

No bugs have been recorded yet.

Bugs will be added here as they are discovered during implementation and testing.

## 3. Debugging Process

When a bug is found, the following process will be followed:

1. Reproduce the bug.
2. Identify the expected behavior.
3. Identify the actual behavior.
4. Find the cause of the problem.
5. Fix the problem.
6. Run the relevant test again.
7. Check that the fix did not introduce another problem.
8. Record the bug and fix in this document.

## 4. Bug Entry Format

Each bug will be documented using this format:

### Bug: [Short descriptive title]

**Problem:**
Describe what went wrong.

**Expected:**
Describe what should have happened.

**Actual:**
Describe what actually happened.

**Cause:**
Describe why the bug occurred.

**Fix:**
Describe how the bug was fixed.

**Testing:**
Describe how the fix was tested.

## 5. Testing and Debugging

Testing will include:

- Normal task creation.
- Listing tasks.
- Getting tasks by ID.
- Updating tasks.
- Deleting tasks.
- Completing tasks.
- Searching tasks.
- Invalid task IDs.
- Empty task titles.
- Invalid status values.
- Empty task list.
- Search with no results.
- Invalid menu choices.

The application will be tested again after bugs are fixed.
